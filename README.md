# Прогнозирование оттока цифровой подписки

[![Build article PDF](https://github.com/QziMan/misis-article-latex/actions/workflows/build.yml/badge.svg)](https://github.com/QziMan/misis-article-latex/actions/workflows/build.yml)

Научная статья Романа Алексеевича Даютова, НИТУ «МИСИС».

Репозиторий: https://github.com/QziMan/misis-article-latex

**Тема:** сравнение логистической регрессии и анализа выживаемости для прогнозирования отключения автопродления основной подписки.

Автор: **Даютов Роман Алексеевич**. Учебная почта: **m2312161@edu.misis.ru**.

## Текущий статус

Подготовлена методическая часть статьи: введение, анализ работ, постановка задачи, описание данных, сравнение методов и протокол исторической проверки. Экспериментальные результаты и успешный бэктест не заявляются. Публикация преподавателя будет добавлена после подтверждения авторства; сейчас она не включена в библиографию.

Компиляция текущего текста проверена встроенным LaTeX-компилятором Codex: успешно. Результат запуска GitHub Actions проверяется отдельно.

## Файлы

- `article.tex` — основной текст, который собирает GitHub Actions.
- `main.tex` — вход для локального просмотра; подключает `article.tex`.
- `misisarticle.cls` — неизменённый класс шаблона МИСИС.
- `.github/workflows/build.yml` — сборка статьи и сохранение PDF.
- `form_fields.md` — краткие формулировки для учебной таблицы.
- `LICENSE` — исходная лицензия шаблона.

## PDF в GitHub Actions

После загрузки проекта в собственный форк включить Actions, если GitHub показывает, что запуск процессов отключён для форков. Сборка выполняется после изменения файлов, для pull request или вручную через **Actions → Build article PDF → Run workflow**. В успешном запуске PDF доступен в **Artifacts → article-pdf**.

Локальная сборка при установленном Tectonic:

```bash
mkdir -p build
tectonic -o build article.tex
```

## Данные и воспроизводимость

Исходные корпоративные данные не публикуются. В репозиторий не входят выгрузки, номера телефонов, технические идентификаторы, параметры подключения к Oracle или файлы с паролями. Число пользователей и окончательные даты выборки указываются после проверки данных. Код обучения может быть добавлен отдельным этапом после согласования схемы обезличенной выборки.

## Происхождение шаблона

Проект подготовлен на основе [sadekovlar/misis-article-latex](https://github.com/sadekovlar/misis-article-latex). Исходный класс `misisarticle.cls` сохранён без изменений. Лицензия класса: LPPL 1.3c или более поздняя. Настройка сборки адаптирована под одну статью.
